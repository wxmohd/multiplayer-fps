# Assets Directory

This folder contains sprites and textures for the multiplayer FPS game.

## Structure
- `weapons/` - Weapon sprites for each theme
- `ui/` - HUD elements, minimap frames, crosshairs
- `effects/` - Muzzle flashes, particles, sparkles

## Sprite Conventions
- All sprites are PNG with transparency
- Weapons are designed for forward-facing viewmodel rendering
- UI elements use consistent sizing (32x32, 64x64, etc.)
- Effects support frame animation (flash_01.png, flash_02.png, etc.)
